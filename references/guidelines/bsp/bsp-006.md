## The recommendation

Repeat the BPE at every routine exam for patients with previous codes 0, 1 or 2. For codes 3 or 4 do not just rescore — perform detailed periodontal charting: code 3 triggers a 6-point pocket chart of that sextant after initial therapy; code 4 triggers a full 6-points-per-tooth chart of the entire dentition both before and after treatment. Once a periodontitis patient is in maintenance, repeat full probing depths annually.

## Why

The BPE is a screen, not a monitor — it cannot show whether sites within a sextant are getting better or worse with treatment because it only records the highest score. To assess response to therapy or progression you need site-specific data, which means a 6-point chart pre- and post-treatment. Code 3 only requires charting of the affected sextant because the disease is contained; code 4 requires whole-mouth charting because deep pockets in one sextant make others probable. Annual full charting in maintenance catches site-specific progression early — by the time it shows up on a BPE rescore the attachment loss is already substantial.

## How this applies in practice

- Codes 0–2: BPE at next check-up. Plaque and bleeding charts as the audit trail.
- Code 3: initial therapy (OHI + RSD), then 6-point chart of that sextant at reassessment.
- Code 4: full-mouth 6-point chart before treatment, repeat after treatment.
- Maintenance phase periodontitis patients: full probing depths recorded at least annually, even when seen mainly by the hygienist.
- A 2 mm change between visits sits within measurement error — but if a furcation tooth or already-advanced site shows a 2 mm loss, treat it as real and act on it.
- Where possible the same clinician should re-chart at reassessment to minimise inter-operator variation.
