## The recommendation

Examine all children from age 7 with a modified BPE of the index teeth (UR6, UR1, UL6, LL6, LL1, LR6); for ages 7–11 record only codes 0, 1 and 2; from age 12 record the full code set including 3, 4 and *.

## Why

Periodontitis can manifest in childhood and adolescence (notably aggressive forms now classified as molar-incisor pattern Stage III/IV Grade C disease) and is missed without probing. Restricting probing to the six index teeth keeps it tolerable for a child while still catching the highest-yield sites. In the 7–11 group, full pocketing is uncommon and the probe is reduced to plaque/bleeding/retention codes only. From 12 upwards the full code set is used because true periodontal pockets become possible and the diagnosis cannot be made without them. A code 3 in 12–17s triggers initial treatment and 3-month review; code 4 or * triggers full assessment and normally a referral.

## How this applies in practice

- Index teeth: upper right 6, upper right 1, upper left 6, lower left 6, lower left 1, lower right 6.
- Use the WHO BPE probe with the same light force as in adults.
- Bleeding alone in a 7-year-old (code 1) usually indicates plaque-induced gingivitis — toothbrushing instruction, not specialist referral.
- Code 4 in a 14-year-old is a red flag — this is the age-band where aggressive periodontitis (now Stage III/IV Grade C) presents.
- Refer Code 4 or * in a child to a paediatric or perio specialist; early intervention is the only chance to preserve the dentition.
- Family history of early tooth loss is the question to ask alongside the BPE in the index-teeth child.
