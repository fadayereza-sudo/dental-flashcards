The dispensary provides 1% hypochlorite solution and 2% chlorhexidine as irrigants.

Our protocol for irrigation is:

- Use hypochlorite as the sole irrigant during canal preparation
- If there is risk of irrigant leakage (i.e. rubber dam seal not satisfactory), use chlorhexidine as the sole irrigant

Do not use both hypochlorite and chlorhexidine for irrigation, if these solutions mix, a hazardous precipitate has been identified. If a change in irrigant is required, always make sure the canal is adequately rinsed with saline before using the other solution.

Povidone iodine 1% is also available for use in cases where the canal is persistently infected.
