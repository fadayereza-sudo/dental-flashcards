## Periodontal screening

A Basic Periodontal Examination (BPE) should be carried out and further periodontal charts should indicate the number and site of pockets greater than 6mm and any mobility detected. Comments regarding oral hygiene, recession should also be included.

### Basic periodontal examination (BPE)

If only BPE of 3 is found in any sextant, this requires initial therapy first (OHI and risk control factor) then a 6-point periodontal pocket chart to that sextant only, while a BPE of 4 in any sextant requires full mouth periodontal chart first, followed by periodontal therapy (info from BPE - British Society of Periodontology, March 2016).

Mark the worse score found in each sextant:

| Code | Finding | Treatment required |
|---|---|---|
| 0 | No disease | No need for periodontal treatment |
| 1 | Bleeding on probing | OHI |
| 2 | Supra or subgingival calculus. Plaque retention factors. No pockets > 3.5mm (Black band completely visible) | OHI + removal of plaque retentive factors + S&P |
| 3 | Shallow pockets 4-5mm (Black band partly visible) | As for code 2 + RSD if required |
| 4 | Deep pockets of ≥ 6mm (Black band disappears) | As for code 3 + Assess the need for complex tx/referral to specialist |
| * | Furcation involvement | — |

WHO Probe markings: 0.5, 3.5, 5.5, 8.5, 11.5mm. Used for BPE examination.
